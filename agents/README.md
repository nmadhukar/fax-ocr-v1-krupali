# Agent Workspace

This directory contains reusable artifacts for AI/automation agents.

## Structure

- `skills/` - subagent skill playbooks
- `tasks/` - repeatable execution tasks (human + machine readable)

## Entry Points

1. Read root `AGENTS.md`.
2. Pick a skill from `agents/skills/README.md`.
3. Execute tasks from `agents/tasks/VIBE_TASKS.md`.
4. Run commands through `scripts/vibe.ps1` or `scripts/vibe.sh`.
